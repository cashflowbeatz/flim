# flim Rooms 0.2.23

**FL Studio 24, 25 and 26 can share a room, with any supported version hosting.** Reviewed
installations: **24.2.2.4597**, **25.2.5.5319**, **26.1.7.5654**. FL24 is supported. Exact
build/fingerprint checks remain; every patch/future update is not established. Older members
joining newer hosts share notes/basic controls while unsupported sounds/features stay unavailable.

## Download and start

Download **flim-rooms-0.2.23-win64.exe** from the release assets. Each person opens the complete
portable app, presses **Get started**, selects FL and creates/joins an eight-digit room. Its
native client is bundled. No signup, extra client, Cloudflare account, Node.js or VPN is needed.
Windows 10/11 x64 and your own supported FL are required.

[First-room guide](https://github.com/cashflowbeatz/flim/blob/main/docs/QUICKSTART.md)

## Included in this first Rooms publication

- Compact desktop app, family-based FL picker, custom install folders, taskbar icon and room controls.
- Any-supported-host mixed-version note/control sharing, recovery copies and missing-plugin
  isolation. Stable VST identity matching supports different local paths/compatible vendor versions.
- Recorded MIDI/piano-roll merging for hosts and members, CRDT identities, duplicate delivery
  handling and preservation of pending local recording during remote edits.
- Referenced-sample delivery, hash verification, retries and a lateral Files sidebar with search,
  direction/status filters, byte progress and a remembered received-files destination.
- Cloudflare Workers/Durable Objects/private R2 backend with persistent R2 safeguards and no
  application 15-minute session timer or daily room quota. Platform/capacity limits remain.
- Bounded queues, stronger parsing/project-load barriers, safer settings/launch behavior, local
  diagnostics, renderer recovery and keyboard/zoom/reduced-motion UI refinements.

## The latest 39 fixes

The last native pass fixes queued preset provenance, formatted-message dispatch, complete
snapshot validation/capacity, lock keys, metadata names/ranges, Unicode labels, remote cursors,
zero/ambiguous VST identities and equivalent Windows paths. It detects silent note/clip insertion
refusal and does not confirm metadata after a native fault.

Repeated queued control values coalesce, control batches yield, optional plugin recovery defers
under queue pressure and unchanged CRDT histories allocate less. These are specific reductions
in work, not an end-to-end latency benchmark.

## Validation and limits

31 native harness executables, 177 desktop backend tests, 127 room/UI checks, 68 Files/UI checks
and 73 local Worker tests passed in the 0.2.23 record. Native fixtures cover nine host/member
pairings. Native transfer loopbacks, real Electron folder/zoom/recovery and portable/unpacked
startup/package checks passed.

No fresh physical MIDI, two-computer, live VST-version or drag/drop session ran in the latest pass.
Earlier live observations are recorded separately. No live audio, arbitrary project/preset
downgrade, encrypted plugin-library extraction or universal VST-state compatibility is provided.
The earlier FL24 recovery-save stall remains a live-testing limitation. Save originals and use
disposable project copies for testing.

This is an unsigned Windows portable build. Verify it using the attached checksums. Update
everyone and start a fresh room; already running FL retains its engine. GitHub publication does
not itself deploy or change a Cloudflare account.

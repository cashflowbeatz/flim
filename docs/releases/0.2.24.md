# Rooms 0.2.24: more reliable notes and shared files

FL Studio **24.2.2.4597, 25.2.5.5319 and 26.1.7.5654** retain mixed-version room support.
Any reviewed version can host. Older receivers share notes/basic controls when a newer project
contains unsupported data. Exact-build checks remain; arbitrary FL patches are not established.

This build adds 34 fixes after 0.2.23. It is published alongside 0.2.25, which includes these
fixes and adds direct sample downloads. For new testing, use 0.2.25 on both computers.

- Larger multi-pattern edits no longer disappear behind an eight-pattern scanner shortcut.
- Complete note snapshots are prepared before any part is queued, including their history budget.
- Unchanged note/playlist contents avoid unnecessary rebuilding; harmless array order changes
  do not become musical edits. Fingerprints use the native lock.
- The receiver verifies actual note/playlist contents, rather than accepting a matching count.
- Sample metadata detects conflicting paths, hashes and sizes. Streaming hashes report crypto
  failures; bounded downloads reject short/oversized bodies and authenticated redirects.
- Concurrent transfers retain separate progress, retry counters restart correctly, and obsolete
  work stops between chunks. Slow filesystem checks no longer hold the shared cache lock.
- Received-file folder validation covers Windows device names, Unicode, missing drives and
  storage failures, with specific recovery messages.

[Read every fix and its purpose](../../client/desktop/QA-0.2.24.md).

Verified: 32 native harnesses, 180 desktop tests, 127 room/UI and 68 Files/UI checks, 73 local
Cloudflare tests, the original relay suite, native transfer loopbacks, real Electron folder/
